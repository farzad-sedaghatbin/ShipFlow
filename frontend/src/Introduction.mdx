# ShipFlow Design System

Welcome to the ShipFlow component library documentation. This Storybook contains all the UI components used in the ShipFlow application.

## 🚀 Getting Started

ShipFlow is a Shape Up methodology tracking application that helps teams manage cycles, pitches, and projects effectively.

### Running Storybook

```bash
npm run storybook
```

### Building for Production

```bash
npm run build-storybook
```

## 🌐 Internationalization (i18n)

ShipFlow supports multiple languages:

- **English** (en) - Default
- **فارسی (Persian/Farsi)** (fa) - RTL support
- **Español (Spanish)** (es)

Use the language switcher in the Storybook toolbar to preview components in different languages.

## 🎨 Theme Support

Components support both light and dark themes. Use the theme switcher in the toolbar to preview different color schemes.

## 📦 Component Categories

### UI Components
Basic building blocks like buttons, inputs, cards, and dialogs.

### Data Display
Components for displaying data like tables, charts, and lists.

### Layout
Layout primitives and containers.

### Feedback
Loading states, error states, and notifications.

### Navigation
Menus, breadcrumbs, and navigation components.

## 🔧 Technologies

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Radix UI** - Accessible primitives
- **React Query** - Data fetching
- **React Router** - Navigation
- **i18next** - Internationalization

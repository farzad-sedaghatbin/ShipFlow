# ShipFlow vs Linear: An Honest Comparison

Linear is excellent. Fast, opinionated, beautifully designed. If you run a pure engineering team doing Scrum-style cycles, it is hard to beat.

ShipFlow is built for a different problem.

## Philosophy

Linear is built around issues, cycles, and engineering velocity. Everything maps to code — branches, PRs, commits.

ShipFlow is built around Shape Up — pitches, hill charts, betting tables. It maps to product thinking, not just engineering execution.

## Key differences

| Feature | ShipFlow | Linear |
|---|---|---|
| Methodology | Shape Up + Kanban + Scrum | Scrum / Cycles |
| Pricing | Free, open source | From $8/user/month |
| Self-hostable | Yes | No |
| Hill charts | Yes | No |
| Betting tables | Yes | No |
| AI-native | Yes | Partial |
| Open source | Yes (MIT) | No |

## Who should use Linear

Teams that live in GitHub, want tight issue-to-PR traceability, and prefer Scrum-style sprints will love Linear.

## Who should use ShipFlow

Teams adopting Shape Up, wanting full data ownership via self-hosting, or needing a free alternative with AI built in should try ShipFlow.

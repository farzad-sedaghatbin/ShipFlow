# Cycles & Getting Started

## What is a Cycle?
A Cycle is a fixed time period (typically 6 weeks) for building features. It is the fundamental unit of work in the Shape Up methodology.

## Cycle Phases
Each cycle moves through these phases in order:
1. **SHAPING** — Ideas are shaped into concrete pitches with clear boundaries
2. **BETTING** — Stakeholders meet at the Betting Table to decide which pitches to work on
3. **BUILD** — Teams work on the selected pitches for the duration of the cycle
4. **COOLDOWN** — A period (usually 2 weeks) between cycles for fixing bugs, exploring ideas, and addressing technical debt

## How to Create a Cycle
1. Navigate to **Cycles** from the sidebar
2. Click **New Cycle**
3. Fill in the cycle name, start date, and end date
4. Select the cycle type (standard 6-week or short 2-week)
5. Click **Create** to save

## How to Manage Cycle Phases
- Cycle phases advance automatically based on dates, or can be manually advanced by an admin
- The current phase is shown on the cycle overview page
- Each phase has specific activities available

## Cooldown Phase
During cooldown:
- Teams fix bugs reported during the previous build phase
- Developers can explore new ideas and prototypes
- Technical debt is addressed
- Cooldown activities can be tracked via the **Cooldown Activities** feature

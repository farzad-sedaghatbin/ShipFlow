# Teams & People

## How to Manage Teams
1. Navigate to **Teams** from the sidebar
2. Click **New Team** to create a team
3. Add team members by searching for people
4. Assign teams to pitches and cycles for workload tracking

## People Management
1. Navigate to **People** from the sidebar
2. View all users in the organization
3. Manage roles and permissions
4. Track individual workload and contributions

## Roles and Permissions
ShipFlow supports role-based access control:
- **Admin** — Full access, organization settings, user management
- **Manager** — Create/edit cycles, pitches, manage teams
- **Member** — View and contribute to assigned pitches and tasks
- **Viewer** — Read-only access

## How to Manage Permissions
1. Go to **Organization Settings** > **Permissions**
2. Create custom roles with specific permissions
3. Assign roles to users

# Projects

## What are Projects?
Projects in ShipFlow organize pitches and tasks into logical groups.

## Project Types
- **Standard** — Full Shape Up process
- **Small Batch** — Shorter cycles for quick iterations
- **R&D** — Exploration-focused, lighter process

## How to Create a Project
1. Navigate to **Projects** from the sidebar
2. Click **New Project**
3. Select the project type
4. Assign a team and configure settings

# Work Logs & Time Tracking

## What are Work Logs?
Work Logs let team members record time spent on tasks and pitches.

## How to Log Work
1. Open a task or pitch detail page
2. Click **Log Work** or use the timer
3. Enter the duration and a description
4. The work log is saved and visible in reports

## Work Log Timer
1. Click the **timer icon** on any task
2. The timer starts counting
3. Click stop when done — the time is automatically logged
4. View your personal work logs under **My Work Logs**

# Meetings

## How to Create a Meeting
1. Navigate to **Meetings** from the sidebar
2. Click **New Meeting**
3. Select the meeting type (Betting, Retrospective, Stand-up, Custom)
4. Add agenda items and participants
5. Record decisions and action items during the meeting

## Meeting Minutes
- Decisions made during meetings are tracked
- Action items can be assigned to team members
- Minutes can be exported for sharing

# Slack Integration

## How to Set Up Slack Integration
1. Go to **Organization Settings** > **Integrations** > **Slack**
2. Click **Connect to Slack**
3. Authorize ShipFlow in your Slack workspace
4. Configure which channels receive notifications
5. Set up Slack commands for creating pitches and logging notes from Slack

## Slack Notifications
- Cycle phase changes
- Pitch approved/rejected
- Circuit breaker alerts
- Retrospective reminders

# Organization Settings

## Key Settings
1. Navigate to **Organization Settings** from the sidebar
2. Available settings include:
   - **General** — Organization name, timezone, language
   - **Capacity Planning** — Default hours per day, working days per week
   - **Circuit Breaker** — Stagnation thresholds and alert channels
   - **Integrations** — Slack, GitHub, Figma, Webhooks
   - **API Tokens** — Personal access token management
   - **Permissions** — Role-based access control

# Custom Metrics & KPIs

## What are Custom Metrics?
Custom Metrics let you define and track your own KPIs beyond the built-in reports.

## How to Create a Custom Metric
1. Navigate to **Custom Metrics** from the sidebar (or via Dashboard widgets)
2. Click **New Metric**
3. Define the metric name, formula, and data source
4. The metric appears on your dashboard and in reports

# Tasks

## How to Create a Task
1. Open a pitch detail page
2. Navigate to the **Tasks** tab
3. Click **Add Task**
4. Fill in title, description, and assignee
5. Set priority and due date

## Task Statuses
- **Open** — Not yet started
- **In Progress** — Currently being worked on
- **Completed** — Done
- **Blocked** — Waiting on something

## Task Dependencies
- Tasks can have dependencies on other tasks
- Blocked tasks show which tasks they depend on
- Dependency chains are visible in the task list

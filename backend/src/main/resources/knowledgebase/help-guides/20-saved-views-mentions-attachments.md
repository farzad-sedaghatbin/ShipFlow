# Saved Views, @Mentions & Attachments

Three everyday features that make working in the backlog and on tasks faster.

# Saved Filter Views

Saved Views let you store a set of backlog filters and reapply them in one click — so you don't rebuild the same filter every day.

## What a Saved View Remembers

A view captures everything you've set on the **Backlog**: status and priority filters, assignee, task category, dependency filter, sort field/order, and the search text.

## How to Save a View

1. On the **Backlog** page, set up the filters, sort, and search you want.
2. Click the **Saved Views** button (bookmark icon) in the filter toolbar.
3. Choose **Save current view**.
4. Give it a name (e.g. "High priority — in progress") and click **Save**.

Views are private to you and scoped to the current project.

## How to Apply, Default, or Delete a View

- **Apply** — click **Saved Views** and pick a view; its filters apply instantly and its name shows on the button.
- **Set as default** — hover a view in the dropdown and click the **star** so it loads automatically when you open that project's backlog.
- **Delete** — hover a view and click the **trash** icon, then confirm.

To "edit" a view, apply it, adjust the filters, save it as a new view, and delete the old one.

You need backlog **read** access to use views and backlog **update** access to create, change, or delete them.

# @Mentions

Mention a teammate in a comment to notify them directly.

## Where and How

You can @mention in **comments on tasks and on bug reports**.

1. In a comment box, type **@**.
2. A dropdown appears with team members; keep typing a name to filter it.
3. Use the **arrow keys** to move, **Enter** to insert, **Esc** to dismiss. For names with spaces, the mention is inserted quoted, e.g. `@"Jane Doe"`.

## What Happens

The mentioned person gets a notification — an in-app notification and, if email is configured, an email. In the rendered comment, mentions appear as blue links; clicking one opens that person's profile popover.

If two people share the exact same display name, the mention can't resolve to a single person, so use the more specific name.

# Task Attachments

Attach files to a task to keep designs, logs, and documents alongside the work.

## What You Can Attach

Images (JPEG, PNG, GIF, WebP, SVG) and documents (PDF, DOC, DOCX, TXT, MD), up to **10 MB per file**.

## How to Upload, View, and Delete

1. Open a **task** and find the **Attachments** card (paperclip icon).
2. **Upload** by dragging a file onto the drop zone, or click it to browse. A progress bar shows the upload.
3. **View** — images show as thumbnails; click any attachment to preview or download it with its original filename.
4. **Delete** — hover the attachment and click the **trash** icon.

If you add files *before* the task is created, they're queued and uploaded automatically once you save the task.

## Permissions

Uploading needs backlog **update** access; downloading needs **read** access. You can delete attachments you uploaded; admins can delete any attachment.

# Kanban Mode

Kanban mode provides a classic board view for teams that prefer a continuous flow over cycles.

## Board columns

The default columns are: **Backlog → Todo → In Progress → In Review → Testing → Done → Archived**

Columns can be toggled on/off per-project via the board settings.

## Creating tasks

Click **New Task** in the Backlog page or directly on the board to create a task.

## Drag and drop

Drag any task card to a different column to change its status. Changes are saved immediately.

## Filters and saved views

Use the filter bar to narrow tasks by status, priority, assignee, or tags. Save frequently-used filter combinations as **Saved Views** with the bookmark icon.

## Bulk operations

Select multiple tasks with the checkbox column, then use the **Bulk Actions** bar to assign, change status, change priority, or delete in one operation.

# Onboarding Tour

ShipFlow includes a 21-step guided tour that walks new users through every key feature.

## Starting the tour

The tour starts automatically on your first login. You can restart it at any time:

1. Click your username in the bottom-left of the sidebar
2. Select **Restart Tour**

## Tour coverage

The tour covers:
1. Dashboard overview
2. Project selector
3. Creating a project
4. Shape Up vs Kanban modes
5. Pitch Board — creating a pitch
6. Moving a pitch through statuses
7. Betting Table — allocating work
8. Creating a cycle
9. Hill Chart — updating scope positions
10. Circuit Breaker
11. Backlog — creating and managing tasks
12. Bulk operations
13. Saved filter views
14. Global search (Cmd+K)
15. @mentions in comments
16. Notifications
17. Reports and dashboards
18. AI Wise Architecture
19. MCP integration
20. Organization settings
21. Your profile

## Skipping steps

Click the **✕** button on any tooltip to pause the tour. Click **Restart Tour** to resume from the beginning.

## For self-hosters

The tour uses [`driver.js`](https://driverjs.com/) and targets elements via `data-tour` attributes. See [`TOUR_GUIDE.md`](https://github.com/farzad-sedaghatbin/ShipFlow/blob/main/TOUR_GUIDE.md) for the full maintenance guide if you customise the UI.

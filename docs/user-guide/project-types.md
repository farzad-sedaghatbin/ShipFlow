# Project Types

ShipFlow supports two project modes. The mode is set per-project and determines the available features and sidebar navigation.

## Shape Up

Full Shape Up lifecycle:
- Pitches, Betting Table, Cycles, Hill Charts, Circuit Breaker, Cooldown
- Sidebar shows: Dashboard, Projects, **Cycles**, Pitches, Betting Table, Health, Retros, Reports, Backlog

## Kanban

Classic Kanban flow:
- Board with 7 configurable columns
- Drag-and-drop between columns
- No cycles or betting table
- Sidebar shows: Dashboard, Projects, Pitches, Health, Reports, **Backlog**

## Switching modes

Project type is set at creation and **cannot be changed once cycles exist**. Create a new project to use a different mode.

## All Projects view

When no specific project is selected, the sidebar shows the full Shape Up navigation. Data displayed is aggregated across all projects.
